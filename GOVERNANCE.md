# Governance

PatchProof is maintained by its contributors. Maintainers are responsible for reviewing security-sensitive changes, release notes, and compatibility policy. Material trust-boundary changes require two maintainer reviews when the project has more than one maintainer.

Decisions should be documented in `docs/decisions/` when they change evidence semantics, runner isolation, GitHub permissions, or public interfaces. The maintainer group may revise this document through a normal pull request; no single maintainer may silently weaken a security default.
