# Support

For setup and configuration questions, read [the quickstart](docs/quickstart.md), [the troubleshooting guide](docs/troubleshooting.md), and the CLI/config references first. Include the PatchProof version, Node/pnpm versions, backend, outcome, and the verifier error list-never include secrets or unredacted logs.

Bug reports and feature requests should use the GitHub templates. Suspected vulnerabilities belong in the private channel described by `SECURITY.md`.
